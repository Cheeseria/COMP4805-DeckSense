# DeckSense

An AI-powered Magic: The Gathering deck analysis and primer generator.

## Setup

1. Install Python 3.10+
2. Install dependencies: `pip install -r requirements.txt`
3. Install Ollama and pull the model: `ollama pull qwen2.5:32b`
